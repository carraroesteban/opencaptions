# Fonts

Served by OpenCaptions itself, so no page loads anything from Google and the fonts work offline. Downloaded from Google Fonts by `scripts/fetch-fonts.js`; each folder has the font's license (SIL Open Font License 1.1), which allows using, embedding and redistributing them.
