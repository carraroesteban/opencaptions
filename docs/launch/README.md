# Launch kit

Ready-to-paste posts for the 1.0 launch, written from the code and the measured numbers in [the overview](../overview.md). Nothing here has been posted. Read each one, change what doesn't sound like you, and post it yourself: several communities ban AI-written posts and contributions (noted below), and every one of them rewards the maker answering questions in person.

| Where | File | When | Rules that matter |
|---|---|---|---|
| Hacker News (Show HN) | [show-hn.md](show-hn.md) | First, on a weekday morning US Eastern, when the demo link works | Must be something people can try; no asking friends to upvote ([Show HN guidelines](https://news.ycombinator.com/showhn.html)) |
| Reddit | [reddit.md](reddit.md) | The days after HN, one community a day | r/selfhosted: projects under 3 months old go in the New Project Megathread only; disclose you're the author ([summary](https://willitstay.com/r/selfhosted), check the sidebar) |
| Product Hunt | [product-hunt.md](product-hunt.md) | A week after HN, 12:01 a.m. Pacific | Hunter optional; the maker answers comments all day |
| LinkedIn and X | [social.md](social.md) | Same day as HN, English and Spanish | |
| awesome-selfhosted | not drafted | From February 2027 | The first release must be more than 4 months old, and LLM-generated contributions are banned ([summary](https://saascity.io/where-to-promote-open-source-projects)): write the entry yourself |
| A 60-second video | [demo-video.md](demo-video.md) | Before HN: every post links it | A real screen recording with sound, not a generated film |

Before posting anything:

1. Deploy the public demo (`deploy/hosted/demo/README.md`) and open `https://try-opencaptions.kvza.ar/s/main` on a phone that isn't on your Wi-Fi.
2. Publish the release with this branch's features, so the download matches the post.
3. Deploy the website, so "New in 1.0" and the guides are live.
