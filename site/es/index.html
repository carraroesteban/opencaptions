Funciones

Todo lo que necesita un evento inclusivo.

Accesible para cada asistente, simple para el equipo el día del evento, y tuyo para siempre.

Para el público

  • Subtítulos en cualquier celularEscaneá el QR de la sala y elegí el idioma. Sin app, sin registrarte.
  • ¿Qué me perdí?Un resumen de los últimos cinco minutos, o de toda la sesión, en su idioma.
  • Preguntale a la charlaRespuestas solo a partir de lo que se dijo, con citas y minuto exacto.
  • TranscripcionesLeé, buscá, imprimí y descargá cada sesión.
  • Pensado para la accesibilidadTamaño de texto, tipografías de alta legibilidad, interlineado, modo claro y oscuro, subtítulos flotantes.

Para el escenario y el streaming

  • Pantalla para el oradorSubtítulos a pantalla completa y el QR de la sala, junto al escenario.
  • Overlay para el streamingTransparente o con chroma para OBS y vMix, en uno o dos idiomas.
  • Oradores multilingüesSi alguien cambia de idioma en medio de la frase, todos los subtítulos lo siguen.
  • Cualquier fuente de audioLa consola a través de una PC, una pestaña del navegador, o una señal de OBS o vMix.

Para la organización

  • Un panel para todas las salasEstado, nivel de audio, demora, público, costo y alertas de un vistazo.
  • Importar la agendaPegá el export de Swapcard, Sessionize o una planilla: los títulos aparecen solos.
  • Carteles con QRUn cartel para imprimir por cada sala, con un clic.
  • Seguro por defectoTokens de acceso, límites de uso y sin puertos entrantes.

Cómo funciona

En vivo en tres pasos.

Conectá el audio

La consola de sonido a través de cualquier PC, una pestaña del navegador, u OBS o vMix apuntando al servidor.

La IA escucha y traduce

Un modelo de voz transcribe cada sala y traduce cada frase con contexto y con tu glosario.

Todos siguen la charla

Celulares, pantalla del escenario y streaming se actualizan juntos. Las transcripciones quedan online.

Capturas

Empezar

Miralo funcionando en dos minutos.

No hace falta API key: los subtítulos son simulados hasta que agregues una.

# Cloná y arrancá en modo demo
$ git clone https://github.com/carraroesteban/opencaptions.git
$ cd opencaptions && npm install
$ npm run mock            # http://localhost:8080

# En otra terminal: reproducí una charla de ejemplo en una sala
$ npm run feed -- --stage main --input samples/talk-en.wav

# ¿Listo para un evento real? Configuralo en un minuto
$ npm run setup
