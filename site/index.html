Features

One server for the whole event.

Thirty rooms ran at once on a laptop in our stress test. Rooms need no operator; the production team watches everything from one dashboard.

For the audience

  • Captions on any phoneScan the room’s QR, pick a language. No app, no sign-up.
  • What did I miss?A summary of the last five minutes, or the whole talk, in your language.
  • Ask the talkAnswers only from what was said, with quotes and timestamps.
  • TranscriptsRead, search, download (TXT, SRT, VTT) and print every talk.
  • Reading settingsText size, high-legibility fonts, spacing, light and dark. Floating captions on laptops.

For the stage and the stream

  • Projector viewLarge captions and the room’s QR code, for the screen next to the speaker.
  • OBS / vMix overlayTransparent or chroma key, optionally bilingual. A visual editor builds the URL.
  • Bilingual speakersWhen a host switches languages mid-sentence, every caption language follows.
  • Any audio sourceThe sound desk through a PC, or OBS/vMix streaming straight to the server (RTMP, SRT, HLS).

For organizers

  • Production dashboardStatus, audio level, latency, audience, cost and alerts for every room.
  • Agenda importPaste your Swapcard, Sessionize or spreadsheet export: talks get their titles.
  • QR postersA printable A4 poster per room, and a one-minute setup wizard.
  • Secure by defaultTokens, rate limits, no inbound ports. Silence isn’t billed.
  • Runs without the cloudWhisper and an open model on your own computer: no API key, audio never leaves the building.

How it works

From the sound desk to every phone.

Plug in the room’s audio

A small agent (or a browser tab) on the room PC sends the sound desk feed. Or point OBS/vMix at the server.

AI transcribes and translates

Gemini Live Translate in the cloud, or Whisper plus an open model on your machine. Captions land in about two seconds.

Everyone reads along

Phones, the projector and the livestream overlay update together. Transcripts stay online afterwards.

Two engines

Cloud quality, or fully local.

Gemini

Best quality and the lowest delay. About US$ 2.2 per room-hour, and silence isn’t billed. Needs internet and an API key.

Local

Whisper and Gemma 3 on your own computer or a GPU box on your network. No API key, no cost per hour, the audio never leaves the building.

Get started

Try it in two minutes.

No API key needed: captions are simulated until you add one.

# Clone and start with simulated captions
$ git clone https://github.com/carraroesteban/opencaptions.git
$ cd opencaptions && npm install
$ npm run mock            # http://localhost:8080

# In another terminal: feed it a sample talk
$ npm run feed -- --stage main --input samples/talk-en.wav

# Ready for real captions? Set up your event
$ npm run setup
